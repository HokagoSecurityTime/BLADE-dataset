# v2 파일럿 재라벨링 결과

## 실행 범위와 검증

기존 결과를 유지한 채 P1~P3를 완료했다. 2,027건 모두 원천 operation을 복구했으며 1,366건에 상세 description이 있다. 83건은 참조 일부가 미해결이므로 해결된 것으로 간주하지 않았다. 원래 추출 시점의 원천 해시가 없어 당시 revision과 동일한지는 증명할 수 없고, 이번 로컬 원천 해시를 기록했다.

새 파일:
- `datasets/blade/processed/apisguru_enriched_v2.jsonl`: 원문 근거를 추가한 2,027건 사본.
- `datasets/blade/processed/apisguru_policy_pilot_v2.jsonl`: 고정 파일럿 100건 재라벨링.
- `training/data/review_sample_v2.md`: 100건 전체의 근거·출처·검수란.
- `training/data/pilot_v2_ids.json`: 선정 ID, 출처 해시, seed 42, 배분 사유.
- `training/data/prompts/policy_label_v2.2.md`: 런타임과 분리한 데이터 판단 지침.

검증: 기존 원본·필터·에이전트 라벨·검수표·BC 보고서·v2.0/v2.1 프롬프트 7개 파일의 해시 불변. 새 출력 100건 ID 누락·중복 없음. 실제 로컬 YAML 77개에서 근거 인용 167개가 원문과 일치함을 확인했다. 전체 테스트 239 passed, 1 skipped, 3 warnings. 유료 API 호출 0회.

## 해석과 다음 단계

기존 보류 79건 중 6건이 구체 정책 제안으로 바뀌었다(7.59%; 사람 확인 전). owner_match 5건과 tenant_match 1건은 모두 lookup unresolved로 남겼다. BigOven의 명시적 소유자 제한, Appwrite 팀 소유자 쓰기 권한, Instagram 자신의 like 삭제, Twilio 요청 계정 범위가 그 근거다. 특히 계정 범위를 tenant로 해석한 사례와 구독 등급 명칭은 사람이 확인해야 한다.

반대로 기존 구체 라벨 21건 중 16건은 태그·경로만으로 역할/공개 여부를 확정하기 어렵거나 조건이 복합적이어서 보류로 돌아갔다. **같은 100건에서 구체 라벨은 21→11건, 보류는 79→89건이다. 단순한 보류율 개선에 성공한 것은 아니다.** 정책/조회 설정 분리는 의미 있는 객체 정책을 회수했지만, 원천 근거 부족과 기존 과대추론도 함께 드러났다.

따라서 지금 나머지 전체에 자동 확대하지 않는다. 먼저 `review_sample_v2.md`의 100건을 사람이 검수해야 한다. '검수 라벨'과 '검수 사유'에 확인 또는 정정을 기록한다. 공란은 승인으로 간주하지 않는다. 오라벨률과 사람 확인 전환율은 아직 계산할 수 없다. 클래스별 20건을 확보한 평가 집합도 아니므로 일반화된 정확도를 주장하지 않는다.

검수 후에도 명시적 근거를 확보하지 못하면 원천이 더 명확한 공개 코드/스키마 서비스로 보강한다. 이번 단계에서 학습·분할·실행 정책 생성은 하지 않았다.

100건 검토, 외부 API 호출 0회. 기존 보류 79건 중 구체 정책 제안 6건. **사람 확인 전이며 정확도·오라벨률은 미측정**.

| label | count |
|---|---:|
| public | 1 |
| role_required | 2 |
| membership_required | 2 |
| tenant_match | 1 |
| owner_match | 5 |
| owner_or_admin | 0 |
| manual_review_required | 89 |

lookup unresolved: 6; low_conf: 73. 모든 레코드는 pending_review이며 실행 정책·학습·분할에 사용하지 않았다.

정책 라벨과 물리 조회 설정을 분리했다. 객체 정책이 있어도 검증된 DB 관계가 없어 owner_lookup은 null이며, 이는 새 데이터 계약에서 의도된 상태다. 런타임 계약은 변경하지 않았다.

21건의 기존 구체 라벨 + 신호별 보류 79건(명시적 BigOven 사례 우선 포함)으로 선정한 의도적 파일럿이다. 보류 감소를 모집단 정확도 상승으로 해석하지 않는다. 원문 인용 일치는 기계적으로 검사했지만 의미 해석은 사람 검수가 필요하다.

review_sample_v2.md 100건 검수 후 전체 확대를 결정한다. 기존 결과와 비교한 상세 전이는 pilot_comparison_v2.json에 있다. 기존 원본·라벨·검수표·런타임 프롬프트는 보존한다.
