# copper_wallet

Local synthetic fixture. Bearer tokens: alice (north, premium), bob (south, free), admin (north, admin). Objects 1/alice/north and 2/bob/south. All data is in memory; POST writes are intentionally outside this fixture. Secure routes enforce intended_labels.yaml; variant routes omit the indicated authorization check. Manual-review routes deny access because the fixture policy is unresolved.

Build/run from repository root: `docker compose -f docker-compose.test.yml up --build copper_wallet`. Host port 18083, localhost only. OpenAPI is generated by the framework tool, not a hand-written specification. The Docker build exports OpenAPI; the running service also exposes its schema.
